# 📝 Personal Blogging Platform

A full-stack blogging platform built with Flask (REST API), MongoDB (Database), and Streamlit (Frontend). This project demonstrates CRUD operations, RESTful API design, and modern web development practices.

## 🌟 Features

### Backend API
- ✅ **RESTful API** with Flask
- ✅ **CRUD Operations** (Create, Read, Update, Delete)
- ✅ **Search Functionality** - Full-text search across posts
- ✅ **Data Validation** - Comprehensive input validation
- ✅ **Error Handling** - Proper HTTP status codes
- ✅ **MongoDB Integration** - NoSQL database with MongoDB Atlas
- ✅ **CORS Support** - Cross-Origin Resource Sharing enabled

### Frontend
- ✅ **Modern UI** - Built with Streamlit
- ✅ **Responsive Design** - Works on all screen sizes
- ✅ **Real-time Updates** - Instant feedback on actions
- ✅ **Search & Filter** - Find posts quickly
- ✅ **Post Management** - Easy create, edit, delete operations
- ✅ **Statistics Dashboard** - View post counts by category

---

## 🛠️ Tech Stack

### Backend
- **Language:** Python 3.12
- **Framework:** Flask 3.0.0
- **Database:** MongoDB Atlas (Cloud)
- **ODM:** PyMongo 4.6.0
- **Additional:** Flask-CORS, python-dotenv

### Frontend
- **Framework:** Streamlit 1.29.0
- **HTTP Client:** Requests 2.31.0

## 📋 Prerequisites

Before running this project, make sure you have:

- Python 3.12 or higher
- MongoDB Atlas account (free tier)
- Git
- pip (Python package manager)
- Virtual environment tool (recommended)
